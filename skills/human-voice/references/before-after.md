# 改前改后：三个完整案例

不是范文，是**手术记录**。看动作怎么落到字上。

> ⚠️ 案例中的数字、文献、人物均为演示虚构。真实写作**必须**用真实数据——编造数据会撞上"事实一致性"检测（虚构引用是最强的 AI 信号），比 AI 味致命得多，且任何改写都救不了。

---

## 案例一：评论 / 议论（人味浓度：高）

### 原文

> 在当今数字化浪潮下，远程办公已成为现代企业的重要工作模式。一方面，它能够提升员工的工作灵活性，显著降低通勤成本与时间损耗；另一方面，它也可能带来沟通效率下降、团队凝聚力减弱等一系列问题。值得注意的是，远程办公并非万能良药，它既带来了机遇，也带来了挑战。因此，企业应当根据自身情况，建立科学合理的远程办公制度，在效率提升与人文关怀之间取得平衡，最终实现组织效能与员工幸福感的双赢。总而言之，远程办公是时代发展的必然趋势，唯有积极拥抱变革，方能在激烈的市场竞争中行稳致远。

### 诊断

| 维度 | 判断 |
|---|---|
| 立场 | **无**。"应当取得平衡"是空结论——任何立场的人都能接受这句话 |
| 具体 | **零**。"很多""一系列""显著"，全部可替换 |
| 节奏 | 5 句，均 42.6 字，CV 0.32，**短句 0%** |
| 取舍 | **无**。删掉任何一句，文章不变 |
| 摩擦 | **无**。全文没有一句可能被反驳 |

脚本：升华词 2（凝聚、行稳致远）｜一方面/另一方面｜口语 0｜疑问 0｜数字 0

**结论：这段文字没有作者，只有语言。不逐句润色，直接重写。**

### 改后

> 我们团队试过全员远程，三个月后撤了。
>
> 不是因为效率——代码提交量反而涨了12%。是新人。两个校招生在群里问了三个月的问题，没一个问对地方：他们不知道谁懂什么，也不知道该在什么时候打断谁。远程把"顺便问一句"这件事删掉了，而这件事恰好是新人长起来的主要通道。
>
> 所以我不太信"远程提升效率"这类结论。它测的是存量团队，而存量团队本来就已经知道彼此知道什么。
>
> 真正的问题在这儿：一个组织的信息，有多少是靠走廊传的？这个数没人统计过，但它决定了你能不能远程。

### 动作对照

| 动作 | 原文 | 改后 |
|---|---|---|
| M1 换骨架 | 从"数字化浪潮"定义式开场 | 从一次失败的具体实验开场 |
| M3 砍三成 | 机遇 / 挑战 / 制度 / 平衡 / 双赢，五点平铺 | 只留一条：新人通道。其余全删 |
| M4 加反例 | 无 | 先把对方最强的一点给出去——"代码提交量反而涨了12%" |
| M5 换论证关系 | 一方面…另一方面（并列，无关系） | 因果链：远程删掉了什么 → 所以新人长不起来 |
| M2 删升华 | "行稳致远""新篇章" | 停在一个未解决的问题上（"这个数没人统计过"） |
| M7 长短手术 | 均 42.6 字，最短 27 字 | 均 21.7 字，最短 3 字（"是新人。"） |
| M9 自我修正 | 无 | "不是因为效率——…是新人。"改口结构 |
| M10 换视角 | 企业视角（无人称） | 管理者 + 新人的双视角 |
| S4 清扫 | 一方面/另一方面、升华词、数字空格 | 全部清零 |

脚本：CV 0.32 → **0.51**｜短句 0% → **11%**｜升华 2 → **0**｜段落 CV 0 → **0.60**

## 案例二：公众号 / 随笔开头（人味浓度：很高）

### 原文

> 在当今快节奏的社会中，越来越多的人开始关注心理健康问题。心理健康不仅关乎个人幸福，也关系到社会的和谐发展。因此，我们应该学会调节情绪，保持积极乐观的心态。

### 改后

> 我妈去年开始失眠。她不说，是我发现她凌晨三点还在朋友圈点赞——赞的都是养生号。
>
> 我问我爸，他说"她一直这样"。这四个字比失眠本身更让我难受。

### 动作对照

| 原文的问题 | 改后怎么处理 |
|---|---|
| "越来越多的人"——无人称，谁都不是 | "我妈"——一个人。一个人的事才有说服力 |
| "应该学会调节情绪"——指令，作者站在高处 | "这四个字比失眠本身更让我难受"——判断 + 情绪，作者在局内 |
| 三段论：现象→意义→应该 | 场景→一个细节→不解释 |
| 全文无一个具体物 | 朋友圈、凌晨三点、养生号、四个字 |

**关键**：改后没有给任何建议。人写东西常常不给建议——这正是它像人的原因。

## 案例三：学术摘要（人味浓度：低，但必须有）

**这一例专门用来纠正一个误解：人味不等于口语化。**

### 原文

> 本文研究了数字化转型对企业创新绩效的影响。通过对A股上市公司2015-2023年数据的实证分析，发现数字化转型显著提升了企业创新绩效。进一步的中介效应检验表明，数字化转型通过缓解融资约束和提升信息透明度两条路径发挥作用。本文的研究丰富了相关文献，对企业实践具有重要启示。

### 改后

> 数字化转型与创新的关系，现有文献基本都报告正相关。但这个结论有个问题：能数字化转型的企业，本来就更可能是那些有钱、有人、有耐心的企业。
>
> 本文用2015—2023年A股数据做的检验，与这个担心一致——控制了企业规模和现金流之后，系数从0.31降到0.09，显著性消失。稳健的只剩一条路径：融资约束的缓解。信息透明度那条在我们的样本里不成立，与李某某（2022）相反，原因可能是样本区间不同。
>
> 对企业来说，这意味着数字化转型本身可能不是杠杆，能拿到钱才是。

### 动作对照

| 动作 | 说明 |
|---|---|
| 立场前置 | "这个结论有个问题"——摘要第一句就表态，不是"本文研究了" |
| 给数字 | 0.31 → 0.09。具体系数比"显著提升"有信息量 |
| 承认局限 | "在我们的样本里不成立""可能是样本区间不同" |
| 承认与文献冲突 | 点名"与李某某（2022）相反"——这是学者会做的事，模型倾向于含糊地说"丰富了相关文献" |
| 结论敢下判断 | "可能不是杠杆，能拿到钱才是"——一个具体的、可能错的推论 |
| 删掉套话 | "丰富了相关文献""具有重要启示"——零信息，全删 |

**注意这里没有一处口语化。** 学术文本的人味是**判断的锋利**：敢说这个结论有问题、敢承认自己的结果和别人的不一样、敢给一个可能被证伪的推论。不是加"其实""说白了"。

---

## 三个案例的共同点

1. **删的比加的多。** 三个案例都是先砍掉一半，剩下的才有形状。
2. **每篇只讲一件事。** 面面俱到是"没有立场"的礼貌说法。
3. **结尾都不升华。** 停在具体层面、未解决的问题、或一个可能错的判断上。
4. **数字、专名、时间必居其一。** 没有具体物的文本，改多少词都是空的。
