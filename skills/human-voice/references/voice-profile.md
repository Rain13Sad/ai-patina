# 定一个声音

人味的本质不是"随机"，是**一致**。一个人写十段话，句长会变、话题会变，但那种"看世界的位置"不变。AI 的问题不是每句都假，是每句都换一个说话的人。

所以模式 B（从零写）和模式 C（文风校准）都要先做这一步：**确定这篇文本里是谁在说话，然后整篇不换人。**

---

## 一、六个维度

| 维度 | 要看什么 | 怎么定 |
|---|---|---|
| **句长** | 平均多少字？最短多短？长短怎么交替？ | 直接数。多数人写 18–30 字，但**短句的位置**比平均长度重要 |
| **人称与距离** | 用"我""我们"还是无主语？把读者当"你"还是"各位"？ | 决定文本的体温。无主语=冷，我=近，我们=有立场 |
| **衔接方式** | 靠逻辑词、靠时间顺序、靠重复关键词，还是靠跳跃？ | 这是最难伪装的一维。模型靠逻辑词，人常常靠"接着说" |
| **比喻来源域** | 比喻从哪个领域取材？ | 这是最强的指纹。写代码的人比喻来自机械和管道，做编辑的来自印刷和裁切，做医生的来自身体 |
| **标点习惯** | 破折号、括号、分号、一句话成段 | 有人从不用分号，有人全靠括号补充 |
| **禁忌词** | 这个人绝对不会说的词 | 比"爱用什么词"更能定位一个人 |

**关键**：六个维度里，"比喻来源域"和"禁忌词"最难被模型自动生成，也最能定住一个声音。优先定这两个。

---

## 二、八种原型（没有样本时选一个）

不要抽象地说"要自然"，选一个具体的人。

| 原型 | 句法特征 | 典型句 |
|---|---|---|
| **谨慎的实践者** | 中长句，多括号补充，常说"我试过""在我们那儿" | "这个方案我试过——在我们那个量级上行得通，再大十倍我没把握。" |
| **尖锐的怀疑者** | 短句多，先否定后给理由，破折号频繁 | "这个结论站不住。不是因为数据少，是因为它只统计了活下来的公司。" |
| **耐心的解释者** | 长句，层层递进，"也就是说""换个说法" | "也就是说，问题不在于他做错了什么，而在于他做对的那件事，只在特定条件下才对。" |
| **局内的观察者** | 用"我们"，但保持距离，行业黑话密度高 | "这事儿在我们内部叫'排期'，其实就是谁先扛不住谁让步。" |
| **老练的编辑** | 极简，删形容词，一句话成段 | "删掉。这句话没有信息。" |
| **好奇的门外汉** | 大量疑问句，承认不懂，比喻来自日常生活 | "我不太懂这个。但如果它真像说的那么便宜，为什么没人做？" |
| **疲惫的一线** | 短句，极具体，有情绪但克制 | "第七版了。改的不是错的地方。" |
| **学究** | 限定条件多，括号像脚注，术语精确 | "严格说这不叫增长（口径不同），但在业务语境里大家就这么用。" |

**用法**：选定一个，把它的句法特征写下来，然后整篇照此执行。不要混用两个原型——混用就是"风格不一致"，而风格一致性本身是被检测的维度。

## 三、从样本提取（模式 C）

用户提供了自己的旧作时，按下面这张表提取。**靠数，不靠感觉。**

```
样本：<文件名>
句长：均 __ 字，最短 __ 字，最长 __ 字。短句出现在（段首 / 转折处 / 结论前）
人称：我 __ 次，我们 __ 次，无主语句 __ 处。对读者称"你/各位/（不称呼）"
衔接：段首逻辑词 __ 次（占比 __%）。主要靠（逻辑词 / 时间 / 重复关键词 / 跳跃）
比喻来源域：__
标点：破折号 __ 处，括号 __ 处，分号 __ 处，一句成段 __ 处
高频私有词：__（出现 3 次以上，且是这个人特有的说法）
禁忌词：__（这个人在样本里一次都没用过，但同类文本里常见的词）
```

提取完，用一句话总结这个声音："一个______的人，在______地说______。"

例："一个做过五年运维的人，在克制地跟同事解释为什么这事不能急。"

写完这句，整篇的语气就定了。写的过程中如果某句不符合这句话，改它。

## 四、两个警告

**1. 不要模仿他人。** Epoch AI 的独立评估发现，AI 被要求模仿特定作者风格时，部分文本能绕过检测——这条路径攻击的是"作者建模"判据。所以只在用户还原**自己**的文风时使用；用来冒充他人（代写、伪造署名文章）越过本技能的边界。

**2. 不要过度特征化。** 把"疲惫的一线"写成满口脏话，把"学究"写成每句三个括号，那是漫画，不是人。人味的密度大概是这样：每 300 字里有 1–2 处明显的个人痕迹，其余部分是普通的、甚至有点笨的表达。

> 普通的、有点笨的表达，本身就是人味。**不要试图让每一句都精彩。** 每句都精彩是 AI 的特征——人在写东西时，大部分句子只是为了把话说完。
