# 痕迹清扫检查表（S4 用）

纯执行步骤。逐项打勾，不需要判断力——但漏一项就白干。

**顺序**：先清扫，后交付。清扫完不要再让模型"整体润色一遍"，那会把刚做的手术抹平。

---

## 零、优先级

| 优先级 | 项目 | 理由 |
|---|---|---|
| P0 | 数字两侧空格 | 不是语言特征，是工具链残留。人手写中文不会这样，检测方一抓一个准，且零成本清除 |
| P0 | 主题升华段 | 中文 AI 文本最稳定的标记，几乎没有例外 |
| P1 | 机械分点 / 三段式 | 结构层痕迹，权重高于用词 |
| P1 | 段段等长 / 总分总 | 同上 |
| P2 | 空转大词、连接词依赖 | 词汇层，影响较小但密度一高就明显 |
| P3 | 破折号、加粗、列表符号 | 排版层，顺手清 |

## 一、中文六大典型痕迹

来自腾讯云 AI 生成识别服务公开的差异特征表，是目前较少见的、把中文 AI 痕迹讲清楚的清单。逐条对照：

| # | 检测特征 | AI 典型表现 | 清扫动作 | 误伤风险 |
|---|---|---|---|---|
| 1 | **主题升华刻意** | "这不仅是爱心传递，更折射社会互助光芒，彰显人性美好本质，凝聚文明进步力量！" | 整段删除。结论停在具体层面 | 低。真需要拔高时，用一句克制的话代替三段排比 |
| 2 | **语义冗余循环** | "阅读能增长知识，因为知识在阅读中积累；阅读可开阔视野，视野随着阅读不断拓宽。" | 每个论点只出现一次。用新信息推进，不要换词重述 | 低 |
| 3 | **分点叙述生硬** | "第一、诚信是立身之本；第二、诚信是交友之基；第三、诚信是社会之魂。" | 改成因果、让步、转折串联 | **中**。公文、合同、制度、操作手册里分点是规范要求，不要动 |
| 4 | **数字前后标准空格** | "考了 97 分，排名第 3 名" | 删除数字两侧空格。中文排版不加空格 | 低。中英混排（"使用 AI 工具"）加空格是排版规范，不必强改 |
| 5 | **相同词语复用** | "这本书很精彩，精彩到让人一读再读，感受其精彩带来的震撼。" | 代词化、省略、换叙述视角 | 低 |
| 6 | **句式单一重复** | "霓虹灯像彩色丝带，路灯像卫士站岗，车灯像流动星河。" | 打散排比，允许句式不整齐 | 低 |

> 第 4 条值得单独记住：**它不是语言问题，是 Markdown 渲染习惯渗进模型输出留下的痕迹。** 这类"非语言痕迹"往往比语言特征更致命，也最容易被忽略。

## 二、结构层

- [ ] **总分总骨架**——首段铺垫、中间三点、末段总结。拆掉，至少拆一头
- [ ] **段段等长**——每段 3–4 句、字数接近。插入一个只有一句话的段落
- [ ] **小标题对仗**——各标题字数相同、都含"与/和/及"。允许不整齐
- [ ] **段落内部固定套路**——论点 + 例子 + 小结，三段循环。打乱
- [ ] **首段铺垫**——"在当今…的背景下"。删掉首段，从第二段开始
- [ ] **结尾总结**——"综上所述""总而言之"。删掉，或换成一句未解决的问题
- [ ] **层级过深**——一、（一）、1.、(1) 四层嵌套。压到两层
- [ ] **列表化代替段落**——该用段落的地方用了 bullet。连续 3 个以上列表就要警惕
- [ ] **论证无代价**——每个方案都"优势明显"，没有取舍。补一句它牺牲了什么

## 三、词汇层


### 连接词依赖

- [ ] 段首"此外 / 然而 / 因此 / 同时 / 总之 / 值得注意的是 / 更重要的是 / 与此同时 / 另一方面 / 由此可见"
- 判据：占比 >30% 就动手。删完读不通，说明两段本来就没关系，该合并

### 句式模板

- [ ] "不仅…而且…""既…又…""在…的背景下""随着…的不断深入""为…提供了有力支撑"
- [ ] "不是…而是…"连续使用（这是 AI 现在的高频结构，用一次有效，用三次就露）
- [ ] 四字短语密度过高。中文 AI 特别爱用四字词凑节奏，人不会那么密
- [ ] 同义轮换——同一概念用四个近义词轮着说。改成固定一个词（见 M12）

## 四、标点与排版

- [ ] **数字两侧空格**（P0）
- [ ] 破折号"——"密度 >3 个/千字
- [ ] 加粗过多。每段都有 `**关键词**`
- [ ] 中英文之间空格不统一
- [ ] 引号混用：直角引号「」与弯引号""混在一起
- [ ] 省略号用"……"还是"..."不统一
- [ ] emoji 装饰性使用
- [ ] 冒号后接列表，连续三段

## 五、英文场景

若文本为英文，额外检查：

- [ ] 高频套词：`delve, tapestry, landscape, realm, navigate, leverage, robust, seamless, holistic, paradigm, underscore, pivotal, intricate, multifaceted, nuanced, testament, foster, showcase`
- [ ] 段首 `Furthermore / Moreover / Additionally / Consequently / Ultimately`
- [ ] "It's not just X, it's Y" 句式
- [ ] "In today's fast-paced world / In an era of"
- [ ] tricolon（三项并列）连续出现
- [ ] em dash 过密
- [ ] "Let's dive in / Let's explore"

## 六、反向清单：这些东西**应该**存在

清扫完如果下面一项都没有，说明文本被磨得太干净了——干净本身就是痕迹。

- [ ] 至少一个具体数字、专名、时间或地点
- [ ] 至少一处代价、失败或反例
- [ ] 至少一次承认不知道、不确定（"我没有数据""说不准"）
- [ ] 至少一处自我修正（"更准确地说""其实是"）
- [ ] 至少一个短句（≤10 字）或一句成段
- [ ] 至少一处括号补充或题外话
- [ ] 至少一个口语词或句末语气词（了/吧/呢/啊）
- [ ] 至少一处故意的重复（同一个词用在两处，因为它是这篇的关键词）
- [ ] 术语上有个人取舍（同一概念固定一个说法，不轮换）

## 七、红线：这些不要碰

以下属于"痕迹层"，技术上可操作，但**法规明文禁止**，且不在本技能范围内：

- 文件元数据中的 AIGC 隐式标识
- 数字水印、隐形 Unicode 字符
- docx 的 XML 属性、修订记录、创建/修改时间戳
- 写作过程证据（版本历史、击键记录、协作日志）

《人工智能生成合成内容标识办法》与 GB 45438-2025：任何组织和个人不得恶意删除、篡改、伪造、隐匿标识，不得为他人实施上述行为提供工具或服务。欧盟《AI 法案》第 50 条同类义务已于 2026 年 8 月 2 日生效。

遇到此类请求，说明边界并停止，不要以"技术上可行"为由继续。

---

## 八、豁免：别把公文改成散文

有些"痕迹"在特定体裁里是规范，不是毛病：

| 体裁 | 应当保留 |
|---|---|
| 公文 / 制度 / 合同 | 分点、编号、层级、"第一条/第二条" |
| 学术论文 | "综上所述"、限定条件、被动语态、术语统一 |
| 操作手册 / 说明书 | 步骤编号、祈使句、无主语 |
| 法律文书 | 同词复用（术语必须一致，不能代词化） |

判断标准：**这个痕迹是体裁要求的，还是模型习惯的？** 前者保留，后者清除。
